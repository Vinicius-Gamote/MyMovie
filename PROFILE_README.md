## About me

I am a full-stack developer focused on the Microsoft and Angular ecosystems. My experience includes building REST APIs, integrating external services, modeling relational data, implementing authentication and authorization, and delivering containerized applications through automated pipelines.

I enjoy turning business requirements into clear technical designs and evolving them into tested, observable, and maintainable software. I apply Domain-Driven Design, SOLID principles, automated testing, and pragmatic engineering practices according to each project's needs.

## Featured projects

### 🎬 [MyMovie](https://github.com/Vinicius-Gamote/MyMovie)

[![MyMovie CI](https://github.com/Vinicius-Gamote/MyMovie/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/Vinicius-Gamote/MyMovie/actions/workflows/ci.yml)

A production-minded movie discovery platform where visitors can browse, search, and inspect movies, while authenticated members can maintain watchlists and publish reviews. Administrators can moderate reviews through a role-protected workflow with an audit trail.

**Engineering highlights:**

- .NET 10 backend organized as a Domain-Driven Design modular monolith.
- Angular 22 frontend with Angular Material and responsive, accessible layouts.
- PostgreSQL persistence with EF Core migrations and domain-backed constraints.
- Secure cookie authentication, anti-forgery protection, authorization, rate limiting, and RFC 9457 Problem Details.
- Server-side TMDB integration with caching, request coalescing, resilience policies, and stale-data fallback.
- Unit, integration, component, and Playwright end-to-end tests.
- Multi-stage Docker images, Docker Compose, health checks, and a GitHub Actions pipeline.

`C#` · `.NET 10` · `Angular 22` · `TypeScript` · `PostgreSQL` · `Docker` · `DDD` · `Playwright`
